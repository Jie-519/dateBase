# 集成操作 · 输入条数即可训练

双击 **`开始训练.bat`**，按提示输入三个条数，程序会自动完成：

```
划分 → 训练 → 收录 → 出图 → 出报告 → 复核
```

全程 5~20 秒（取决于跑几组），结束后在浏览器打开生成的展品页。

---

## 一、怎么用

### 1. 双击 `开始训练.bat`

出现控制台后，按提示输入（直接回车 = 用括号里的默认值）：

```
  训练集条数（默认 2349）: 2349
  验证集条数（默认 505）: 505
  测试集条数（默认 500）: 500
    [1] 五组全跑（G0 G1 G2 G3 G3p）—— 报告最完整
    [2] 只跑主模型（G2）—— 最快
    [3] 主模型 + 两组泄漏对照（G2 G3 G3p）
  用哪套？（默认 1）: 1
  开始？(Y/n):
```

### 2. 输错会怎样

程序会说明原因并要求重输，不会带着错误参数往下跑：

| 输入情况 | 提示 |
|---|---|
| 三者之和 > 3354 | 「三者之和 3600 超过材料总数 3354，请重输」 |
| 训练集 < 1000 | 「必须在 1000 ~ 3354 之间」 |
| 输入了文字 | 「要输入整数，收到 'abc'」 |
| 验证/测试 < 100 | 同上，按各自下限提示 |

**三者之和可以小于 3354**：少的那部分进「未使用池」，既不训练也不评估，也**不会写进训练文件**。

### 3. 结果在哪

```
图与报告\exhibit\<dataset_id>\index.html
```

`dataset_id` 长这样：`c2db-T1500-V200-S200-s42`（T=训练、V=验证、S=测试、s=seed），
看见名字就知道这份划分是怎么来的。

展品目录里有：

| 内容 | 说明 |
|---|---|
| `index.html` | 总看板：排行榜 + 对比图 + 全部训练表 |
| `report/<run_id>.html` | 每次训练一份报告，图已内嵌，可单独转发 |
| `fig_*.png` | 全部图片，可单独取用 |

## 二、命令行用法（等价，便于批量/自动化）

```bat
cd D:\数据库\集成操作

python run.py                                          :: 交互模式
python run.py --train 2349 --valid 505 --test 500      :: 直接给参数
python run.py --train 1500 --valid 200 --test 200 --groups G2
python run.py --train 2349 --valid 505 --test 500 --open   :: 完成后自动打开浏览器
```

`--groups` 可选：`G2` / `G2,G3` / `G0,G1,G2,G3,G3p`。

## 三、它到底做了什么

| 步骤 | 做什么 | 产物 |
|---|---|---|
| ① 生成划分 | 按化学式整组 + 分层 + 精确修补 | `管理器/snapshots/<dataset_id>.{csv,split.json,features.json}` |
| ② 训练 | 逐组调用原版 `train.py`（**不改它一行**，用环境变量切数据集） | `训练数据/XGboost/<run_id>/` |
| ③ 收录 | 校验产物哈希、打标（冒烟/泄漏） | `管理器/catalog.sqlite` |
| ④ 出图 | 每组的预测/残差/学习曲线/重要性 + 跨组对比 | `图与报告/exhibit/<id>/fig_*.png` |
| ⑤ 出报告 | 单次报告 + 总看板（图 base64 内嵌） | `图与报告/exhibit/<id>/*.html` |
| ⑥ 复核 | 重读快照，核对三集条数与零交叠 | 控制台打印 |

**测试集隔离**在这一整条链路上有四处独立保证：划分算法（四桶互斥）、落盘前自检（交叠即中止）、
文件层（未使用与测试材料不在训练 CSV 里）、单元测试（断言 `train∩test = ∅`）。

## 四、常见问题

**Q：提示「没找到 Python」**
装 Python 3.11+，安装时勾选 *Add python.exe to PATH*；或把 `开始训练.bat` 里的 `python` 改成完整路径。

**Q：能同时开两个窗口跑吗？**
不要。台账是单机 SQLite，并发写会冲突；一个跑完再开下一个。

**Q：展品太多了怎么办**
超过 20 套时程序会提示（**不自动删除**）。手动删掉 `图与报告\exhibit\` 下不要的目录即可；
台账里的记录会保留，重新生成同名 `dataset_id` 会覆盖对应展品。

**Q：同样的条数跑两次，结果一样吗**
划分完全一样（同输入必同输出）；训练指标也一致（`nthread=1` + 固定 seed，容差 1e-6）。
但每次是新的 `run_id`，台账会多记一条。

**Q：能改默认条数/下限吗**
下限在 `管理器\paths.py` 的 `MIN_SIZES`；默认条数在 `run.py` 的 `interactive()` 里。

## 五、目录

```
D:\数据库\
├── 集成操作\
│   ├── 开始训练.bat     ← 双击这个
│   ├── run.py           ← 编排脚本（真正的逻辑）
│   └── README.md        ← 本文件
├── 模型\
│   ├── 管理器\          ← 划分/台账/出图/报告（算法都在这里）
│   └── XGboost\         ← 只放脚本与依赖
│       └── train_XGboost\   ← 原版训练脚本
├── 训练数据\            ← 按模型名分目录，一个模型一个文件夹
│   └── XGboost\<run_id>\    ← 每次训练一个目录
└── 图与报告\            ← 跨模型、按数据集组织，可重画
    ├── index.html           ← 母集展品看板
    └── exhibit\<dataset_id>\ ← 每次生成的展品
```
